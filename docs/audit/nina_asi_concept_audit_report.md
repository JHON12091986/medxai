## 🔥 Critical ROI Concepts

### 1. Semantic Router (`core/semantic_router.py`)
**Status**: ✅ Implemented
**Current Implementation**:
- Uses `sentence-transformers` (`all-MiniLM-L6-v2`) for embeddings.
- Routes queries to relevant files/agents.
- Loads `nina_index.json` for file metadata.

**Gaps**:
- No dynamic reindexing of embeddings on file changes.

**Action Plan**:
- Integrate with `Post-Commit Snake Hook` to reindex embeddings when `.py` files change.

---

### 2. MemoCache (`core/memo_cache.py`)
**Status**: ✅ Implemented
**Current Implementation**:
- Hash-based caching (`SHA256(prompt+context)`).
- TTL support (7 days).
- Thread-safe atomic writes.

**Gaps**:
- No `@memo_cache` decorator.
- No cache stats or LRU eviction.

**Action Plan**:
- Add decorator for LLM calls.
- Implement `cache_stats()` and LRU eviction.

---

### 3. Context Compressor (`core/context_compressor.py`)
**Status**: ✅ Implemented
**Current Implementation**:
- AST-aware extraction of functions/classes.
- Keyword-based scoring for relevance.
- Multi-file compression.

**Gaps**:
- No semantic scoring (embeddings).
- No caching of compressed chunks.

**Action Plan**:
- Replace keyword scoring with `sentence-transformers`.
- Cache compressed chunks in `data/compressed_cache/`.

---

### 4. SSOT Index JSON (`docs/space/nina_index.json`)
**Status**: ✅ Implemented
**Current Implementation**:
- Generated by `tools/update_index.py`.
- Includes `path`, `category`, `role`, `lifecycle`, `summary`.

**Gaps**:
- Missing `purpose` and `owner` fields.

**Action Plan**:
- Parse `CODEBASE_MAP.md` to add `purpose` and `owner`.

---

### 5. Post-Commit Snake Hook (`git-hooks/post-commit`)
**Status**: ✅ Implemented
**Current Implementation**:
- Runs on every commit.
- Triggers `core.guardian_loop` for changed Python files.
- Non-blocking and logged.

**Gaps**:
- Does not update `nina_index.json` or run dedup/reindexing.

**Action Plan**:
- Extend to run `tools/update_index.py`, `scripts/dedup_scanner.py`, and `scripts/reindex_embeddings.py`.

---
