# NINA Core Infrastructure — Usage Guide\n\n## Quick Start\n\nEvery agent, component, and script in NINA imports from `core` directly:\n\n```python\nfrom core import (\n    get_cached, set_cached, cache_key,   # memoization\n    count_tokens, fits_budget,            # token budgeting\n    route_query, route_agent,             # semantic routing\n    compress_file,                        # context compression\n    should_run, mark_done,               # idempotency\n)\n```\n\n---\n\n## Module Reference\n\n### `core.memo_cache` — Zero-Token Repeat Calls\n```python\nfrom core.memo_cache import get_cached, set_cached, cache_key\n\nkey = cache_key(prompt, context_str)\nresult = get_cached(key)\nif result is None:\n    result = call_llm(prompt)\n    set_cached(key, result, ttl=3600*24*7)\n```\n\n### `core.token_counter` — Pre-flight Token Check\n```python\nfrom core.token_counter import fits_budget, trim_to_budget, token_report\n\nif not fits_budget(prompt, max_tokens=4096):\n    prompt = trim_to_budget(prompt, max_tokens=4096)\n\nreport = token_report({\"system\": sys_prompt, \"user\": user_msg, \"ctx\": context})\n# {\"system\": 312, \"user\": 45, \"ctx\": 1820, \"TOTAL\": 2177, \"BUDGET_REMAINING\": 1919}\n```\n\n### `core.semantic_router` — No-LLM File/Agent Routing\n```python\nfrom core.semantic_router import route_query, route_agent\n\nresults = route_query(\"telegram message handler\", top_k=3)\nagent = route_agent(\"parse user intent from message\")\n```\n\n### `core.context_compressor` — AST-Aware File Compression\n```python\nfrom core.context_compressor import compress_file, compress_for_query\n\nctx = compress_file(\"core/semantic_router.py\", query=\"cosine similarity\")\nctx = compress_for_query([\"agents/planner.py\", \"core/memo_cache.py\"], \"caching logic\", max_chars=8000)\n```\n\n### `core.idempotency` — Safe-to-Run-Twice Scripts\n```python\nfrom core.idempotency import should_run, mark_done\nimport sys\n\nINPUTS = [\"data/ssot_index.json\"]\nif not should_run(\"build_embeddings\", inputs=INPUTS):\n    sys.exit(0)\n# ... do expensive work ...\nmark_done(\"build_embeddings\", inputs=INPUTS)\n```\n\n---\n\n## Snake Loop — Install Once, Runs Forever\n\n```bash\ngit config core.hooksPath git-hooks\n```\n\nAfter every `git commit`:\n1. Delta-updates `data/ssot_index.json` (only changed files)\n2. Scans for duplicate functions/prompts → appends to `jules_backlog.md`\n3. Runs arch validation / vulture\n4. Rebuilds embeddings if SSOT changed\n5. Initializes example bank if missing\n\n---\n\n## Token Budget Guide\n\n| Component | Max Tokens | Strategy |\n|-----------|-----------|----------|\n| Telegram agent | 2,048 | Compress context + cache responses |\n| Planner agent | 4,096 | CoT + few-shot from example_bank |\n| MCP tools | 1,024 | Token counter gate before every call |\n| Full file read | 8,192 | Always use compress_file() |\n\n---\n\n## Setup Symlinks (Run Once)\n\n```bash\nbash scripts/setup_symlinks.sh\n```\n\nSymlinks `config/` files and `core/` modules into every agent dir.\nAny future change to `config/` or `core/` propagates to ALL agents automatically.\n
