
   - Example:
     ```python
     def complex_function(arg1, arg2):
         """Summary line.

         Extended description of the function.

         Args:
             arg1 (type): Description of arg1.

         Returns:
             type: Description of return value.
         """
     ```
5. **Include Key Sections**: For functions and methods, include:

   - **Returns**: Description of the return value, including type.
   - **Raises**: Any exceptions that may be raised.
   - **Examples**: Example usage (optional but recommended).
6. **Class Docstrings**: Document the class purpose, attributes, and methods.
7. **Module Docstrings**: Document the module's purpose and contents.
8. **Consistency**: Use a consistent format (e.g., Google, NumPy, or reStructuredText) across the project.
9. **Avoid Redundancy**: Do not repeat information that is already clear from the function signature (e.g., parameter names).
10. **Update Docstrings**: Keep docstrings up-to-date with code changes.
