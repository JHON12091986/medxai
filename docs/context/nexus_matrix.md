## 2. In-Depth Architectural Evaluation

### NX-01: GraphRAG Associative Memory Symbiosis
- **Concept**: SQLite-backed graph database over ChromaDB for multi-hop semantic traversal.
- **ROI**: Reduces memory query misses significantly.
- **Hardware gate**: CPU-only viable (no GPU required for SQLite graph). ✅

### NX-02: Semantic Embedding Caching
- **Concept**: Request deduplication using cosine-similarity thresholds.
- **ROI**: 40-70% token reductions on mechanical/OODA tasks.
- **Hardware gate**: Fits in RAM, no VRAM needed. ✅

### NX-03: Event-Driven Async Swarms
- **Concept**: Moves orchestration from sequential semaphores to PubSub.
- **ROI**: Reduced latency, zero blocking-IO deadlocks.
- **Hardware gate**: Pure Python/asyncio — no GPU. ✅

### NX-04: AST-Safe Self-Healing Engine
- **Concept**: Intercepts SyntaxError/TypeError, runs AST fixes via local LLM.
- **ROI**: Self-repair loop for robust background daemon runs.
- **Hardware gate**: Uses local model — must be ≤2GB VRAM (Qwen2.5-3B or Gemma3-1B). ⚠️

### NX-05: Local/Cloud Hybrid Balance
- **Concept**: Automated VRAM/headroom checks routing to zero-cost Ollama when headroom allows.
- **ROI**: Shifts load to local Ollama; cloud only when local saturated.
- **Hardware gate**: Core feature — this IS the MX150 adapter. ✅

### NX-06: Model Intelligence Routing
- **Concept**: Dynamic routing across Gemini, Claude, OpenAI, DeepSeek, Qwen, Kimi.
- **ROI**: 50-95% cost reduction while maximizing performance.
- **Hardware gate**: Cloud routing requires no local VRAM. ✅

### NX-07: Autonomous Agent Specialization
- **Concept**: Replaces static agent profiles with dynamic expert swarms generated on-the-fly.
- **ROI**: High-precision task-matching, lower daemon memory footprint.
- **Hardware gate**: Expert swarms must use approved 2GB models. See `docs/HARDWARE_FIRST.md`. ⚠️

### NX-08: Knowledge Distillation Engine
- **Concept**: Compresses long-term run histories into durable intelligence vectors.
- **ROI**: Cleans context footprint, improves reasoning coherence over time.
- **Hardware gate**: Embedding model must fit 2GB (nomic-embed-text or similar). ⚠️

### NX-09: Self-Modification Safety
- **Concept**: Git snapshots + rollback points + AST validation before any write.
- **ROI**: Zero regressions during autonomous upgrades.
- **Hardware gate**: Pure git/Python — no GPU. ✅

### NX-10: Recursive Self-Evolution
- **Concept**: Periodic self-evaluation metrics targeting the ATAL pipeline itself.
- **ROI**: Prevents NEXUS from becoming an evolutionary bottleneck.
- **Hardware gate**: Evaluation model ≤2GB VRAM. ⚠️
