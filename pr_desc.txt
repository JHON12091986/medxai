💡 What: Replaced inline dictionary unions (`PROVIDERS_TIER1 | PROVIDERS_TIER2 | ...`) with a precomputed `ALL_PROVIDERS` dictionary at the module level.
🎯 Why: In Python, `dict_a | dict_b` creates a brand-new dictionary object every time. Doing this repeatedly inside hot paths like `_has_key` and API routing lookups is highly inefficient.
📊 Impact: Eliminates redundant O(N) memory allocations and lookup overhead on every router call, reducing CPU cycles and improving local routing latency.
🔬 Measurement: Verify changes in `core/router.py`. Profiling local dictionary allocations confirms that replacing the bitwise dictionary union operator with `.get()` queries against a constant module-level dictionary executes significantly faster.
